  * **K3**: Khảo sát hiện trạng, ứng xử chuẩn mực, không ồn ào ảnh hưởng khách của tiệm
  * **K4**: Báo giá niêm yết linh kiện theo cốp xe (Thợ nhận 80% • Sàn giữ 20%)

## 🚀 HƯỚNG DẪN KHỞI CHẠY & TRIỂN KHAI

### 1. Chạy trên máy tính cá nhân (Local Server)
```bash
# Cài đặt và khởi chạy server
node server.js
```
Mở trình duyệt truy cập: `http://localhost:3456`

### 2. Triển khai tự động lên Vercel
1. Đẩy mã nguồn lên GitHub repository: `https://github.com/thuongmaidatphu-bit/datphu-onebase.git`
2. Đăng nhập [Vercel](https://vercel.com) với tài khoản GitHub.
3. Chọn dự án `datphu-onebase` và nhấn **Deploy**.
4. Website sẽ online ngay lập tức với tên miền toàn cầu: `https://datphu-onebase.vercel.app` (hỗ trợ SSL/HTTPS miễn phí).
