## 🌟 Tính Năng Nổi Bật

1. **Phân Hệ B2B: Cứu Hộ Khẩn Cấp 15 Phút Cho Tiệm & Shop**
   - Tiệm Tóc / Barbershop (Xử lý bồn gội, máy uốn, chập điện quá tải)
   - Tiệm Nail / Spa (Xử lý bồn ngâm chân, hệ thống hút mùi, máy hơ gel)
   - Tiệm Trà & Quán Cafe (Xử lý máy đá, tủ mát, bẫy mỡ bồn rửa)
   - Tiệm Bánh & Bakery (Xử lý lò nướng, tủ bảo quản bánh kem)
2. **Quy Chuẩn Kiểm Toán 6K (Kín Kẽ OS)**
   - K1: Tiếp nhận & Định vị GPS
   - K2: Thợ nhận việc, xác nhận lộ trình
   - K3: Khảo sát hiện trạng, không ồn ào ảnh hưởng khách
   - K4: Báo giá niêm yết linh kiện cốp xe
   - K5: Thi công & Nghiệm thu
   - K6: Hóa đơn điện tử (Ký hiệu 1C26TDP) & Bảo hành số 30 ngày
3. **Cơ Sở Dữ Liệu Cloud Supabase Realtime**
   - Kết nối trực tiếp máy chủ Supabase qua REST API
   - Đồng bộ tức thì giữa Khách đặt và Dashboard điều phối

## 🚀 Hướng Dẫn Triển Khai (Deploy)

### 1. Triển khai lên Vercel
1. Đẩy mã nguồn lên GitHub.
2. Đăng nhập [Vercel](https://vercel.com) -> Bấm **Add New Project**.
3. Chọn kho chứa GitHub `datphu-onebase` và bấm **Deploy**.
4. Website sẽ online ngay lập tức với tên miền miễn phí dạng: `https://datphu-onebase.vercel.app`.
